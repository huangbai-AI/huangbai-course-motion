# 黄白课程包装动效

为课程口播、概念解释、步骤流程和作品展示制作深蓝紫包装。先由 imagegen 设计关键帧，再用可独立编辑的图形、文字和素材制作动效。

当前版本为 **1.1.0**。[下载完整技能包](https://github.com/huangbai-AI/huangbai-course-motion/releases/tag/v1.1.0)

## 在 Codex 中使用

1. 下载并解压，将整个 `huangbai-course-motion` 文件夹放入 `~/.codex/skills/`。
2. 在新对话中输入「使用 $huangbai-course-motion，按这段口播设计一条课程包装动效」，并附上口播和参考素材。
3. 从技能入口开始，按任务读取相应资料。[技能入口](SKILL.md)

## 包内资料

- 从设计委托到导出的完整流程和 7 组可改写的生图提示词。[制作方法](references/production-playbook.md) · [提示词](references/prompt-recipes.md)
- 白色面型图标、背景、认可稿和反例，包含图标内部层级与文字密度的检查规则。[图形讲解与反例](references/visual-explanation.md)
- 素材拆分脚本和可运行的动效起步工程，附字体配置与导出方法。[起步工程用法](references/starter-and-scripts.md)
